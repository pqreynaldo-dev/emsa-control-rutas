# EMSA Cochabamba — Control de Rutas

Página web para el **registro y control de rutas de recolección** de la Empresa Municipal de Servicio de Aseo (EMSA) de Cochabamba, Bolivia.

## Descripción

Sistema tipo tablero de despacho que permite registrar rutas de recolección, asignar vehículo y cuadrilla, definir el turno y seguir el estado de cada ruta (Programada, En ruta, Completada) desde una sola vista.

## Características

- Registro de rutas con código automático, zona, vehículo, cuadrilla, turno y frecuencia.
- Tablero de rutas en vivo con estados y filtros por turno y por zona.
- Contadores automáticos: rutas registradas, rutas en ruta y zonas cubiertas.
- Vista de cobertura con el número de rutas activas por zona.
- Diseño responsivo (funciona en celular y escritorio).

## Tecnologías

- HTML5
- CSS3 (sin frameworks, estilos propios)
- JavaScript (sin librerías, todo en memoria durante la sesión)

## Uso

Abre `index.html` en tu navegador, o publícalo con GitHub Pages.
